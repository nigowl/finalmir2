# 五职业伤害检查

## 已修正的弓箭普射

普通箭沿用原引擎DC和ACAgility，技能箭沿用MC及各自防御类型。当前版本弓武器的DC与MC不同，不能只把普箭改为MC来提高伤害。

原距离命中式在九格为`100-(100/9)*9=1%`，导致最远射程的普箭几乎全部落空。现在基础命中从近端100%降至九格50%，继续应用`RangeAccuracyBonus`、专注翻倍及原敏捷二次判定，最终限制在0–100。人物与英雄共用该规则。

`HumanObject.RangeAttack`同时检查原`CanAttack`及目标的真实当前射程，死亡、冰冻、攻击冷却和伪造包内坐标不能绕过这些限制；原墙体、攻击权限及弹道处理保留。

## 当前版本采样

2026-11-26在隔离版本运行`--class-balance-audit 输出JSON绝对路径`：五职业分别取10、20、30、40级，使用当前版本合法且价格不高于10万的武器及普通技能定义。沿用宿主装载全部配方，以免只读LoadDB漏掉配方引用；每个样本400次原攻击/施法，读取实际HP/MP差值；每次恢复武器耐久，近战站一格，远程技能站六格，防御取等级除以5。时间估算使用原AttackSpeed或技能间隔，不实际等待整个时长。

## 验证入口和边界

- `--archer-attack-checks`：人物/英雄真实扣血、DC不误换MC、冷却/死亡/冰冻、伪造射程、墙体和切图后弹道。
- `--class-balance-audit`：只允许`mir2-balance.`隔离目录，只读加载世界，不保存正式账户。
- 完整兼容性还覆盖现有五职业技能组合与原权限判断；这些检查不等同全部装备、AOE、召唤、长战耗蓝、长期经济或多人PvP验证。

英雄与人物使用同一系统自动学习开关及各自职业勾选列表，在各自升级时按真实书籍、职业/性别/等级/属性条件补学；英雄额外遵守NoHero。保存设置或登录不立即补学，不耗书/金币，不重置熟练度和快捷键。

公共商城仅允许书籍等级要求和技能初学等级均低于35的技能书。旧货架可读取但展示及购买过滤，后台保存拒绝违规书；不删除已持有高阶书、不改NPC货架，也不限制系统配置的高阶自动学习。

# 陪玩实现与可靠性检查（2026-11-12）

结论：已实现可管理、可独立按规则成长的陪玩，并通过真实协议、浏览器、故障注入和隔离版本检查。可以用于受控的小规模使用；两人短时采样不能证明几十/上百陪玩连续数日运行稳定，也不能保证任意第三方剧情版本全部自动通关。具体操作见 [管理手册](COMPANIONS_OPERATIONS.md)。

所有测试使用临时完整版本和独立端口；素材库只读复用。没有在正式default创建测试账户、重启正式实例或覆盖正式发布目录。

| 模型返回正文慢或恶意返回命令 | 总超时5秒、响应32KiB上限、严格文本JSON、命令前缀拒绝；本地HTTP故障服务覆盖 |
| 测试模型后修改配置，可能显示旧配置的成功结果 | 返回结果绑定发起时配置，输入改变即失效；浏览器模拟延迟响应验证 |
| 批量写到一半失败留下部分档案 | 同一事务写入所有档案及昵称池；中间INSERT注入失败后查无任何新增，重试不重复创建 |
| 地图下载与旧执行会话暂存可能累积 | 每会话只保留当前内存地图，解析后删除暂存，已结束会话释放资源；双陪玩采样检查 |

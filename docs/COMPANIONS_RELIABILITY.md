| 陪玩存储或监管异常可能冒泡到游戏宿主 | 停止陪玩、兼容页显示阻断，保留游戏宿主；对用量UPDATE注入SQLite故障并恢复 |
| 陪玩绑定先落库而原账户后保存，中途退出可能两边不一致 | 绑定与原账户/角色快照同一事务；账户写失败时内存和SQLite绑定一起撤回 |
| 注册记录在拒绝之后才清理，达到上限可能永久等待 | 原注册及陪玩排队共用先清理过期记录，再执行原每小时上限；边界回归 |
| 多模型混用密钥/清空错误模型、删除被引用模型 | 稳定编号选择，单独保留/替换/清除；引用保护、旧单模型迁移及真实HTTP请求验证 |
| 模型返回正文慢或恶意返回命令 | 总超时5秒、响应32KiB上限、严格文本JSON、命令前缀拒绝；本地HTTP故障服务覆盖 |
| 测试模型后修改配置，可能显示旧配置的成功结果 | 返回结果绑定发起时配置，输入改变即失效；浏览器模拟延迟响应验证 |
| 批量写到一半失败留下部分档案 | 同一事务写入所有档案及昵称池；中间INSERT注入失败后查无任何新增，重试不重复创建 |
| 地图下载与旧执行会话暂存可能累积 | 每会话只保留当前内存地图，解析后删除暂存，已结束会话释放资源；双陪玩采样检查 |

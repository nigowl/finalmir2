# 陪玩练级与玩法测试指南

等级用来缩小选择范围。实际能不能打，要看职业、命中率、装备耐久、已学技能、红蓝药和承伤。先补给、修理和交付能完成的任务。缺药且付不起药费时，优先按原安全检查筹资；状态恢复后重新选择任务或练级去处。

下列地点和怪物来自 default 当前刷怪和怪物定义，可作为路线起点。表中经验是怪物基础值，实际经验以原服的等级差、组队和倍率计算为准。

| 角色等级 | 练级起点 | 何时换目标 |
| --- | --- | --- |
| 1–9 | 比奇省 #1 的鸡 #29、鹿 #30、稻草人 #39 | 职业入门任务、武器和补给稳定后换更高经验的怪。原版鹿和稻草人标注等级较高，仍可按实际攻防判断。 |
| 10–19 | 比奇省 #1 的多钩猫 #42、钉耙猫 #44、半兽人 #48、森林蜘蛛 #46 | 肉或普通金币还可用来筹资，但经验衰减后不继续把它们当长期练级目标。 |
| 20–29 | 天然洞穴 #34 的骷髅 #85、掷斧骷髅 #90；能稳定应付时试沃玛森林（北）#108 的半兽战士 #50 | 能及时用药且装备耐久足够，再逐步试僵尸或昆虫洞穴；缺药时不要深入矿洞。 |
| 30–39 | 沃玛森林（北）#108 的半兽勇士 #52，或昆虫洞穴·第1层 #65 的蓝纹蛛 #233、赤纹蛛 #231 | 按实付药费和击杀耗时换场，避免用单怪可打推断一群也能打。 |
| 40+ | 可先试有任务来源的中阶区域，如南·山谷废弃矿洞 #150 的腐朽巫尸 #133、地下1层·石墓 #200 的红野猪 #168。 | 若怪物经验已经大幅衰减，考虑安全可达的高收益怪。祖玛和猫妖地图需更强的实际战力、耐久和药量，不能仅凭40级去打。 |

1–9级已持可用武器且附近64格内有适合的正常经验来源时，先就近成长，不为超过64格或异图的普通猎杀任务长途赶路；到10级恢复原任务。补给、修理、真实交付、缺武器恢复和盟重日常优先级不变，没有附近合法目标仍继续原任务。

普通练级在当前可走到的地图中，比较等级差修正后的经验与预估普攻击杀及路程耗时。用到当前首个出口的格距和公开跨图次数估算成本，安全且明显更划算的跨图目标可以排在本图低收益怪之前。生命不超过65%时不为普通练级选跨图目标。任务、筹资、补给和个人战力/地图权限保留原优先级，战力不足时仍会留在较低级区域。排序只是估值，不能替代整段路径与围攻判断。

单次测试资助先选一个明确的陪玩与测试目的，核对角色和账号绑定、当前余额、道具编号和背包，使用原管理端角色物品发放及账户金币编辑，要求账户完全离线、当前版本校验和目标确认。记录发放前后、唯一编号和正常落盘；资助后仍由陪玩走原NPC、真实扣费和邀请流程。行会需要检查原费用及材料，师徒和夫妻还需要验证原请求、双方同意和关系规则，金币或物品到账不算关系成立。没有定期发放或自动补发。

default 的师徒设置要求同职业，且相差至少10级；婚姻配置最低10级。陪玩目前没有自主发起和接收这两类关系的流程，后续从原请求和双方确认开始做专项回归。

新手效率回归：`python3 tests/Companions/efficiency.py --source-version=<版本目录> --server-dll=<独立候选DLL> --seconds=1200`。通过SQLite只读备份构造空身份隔离版本，五职业正常注册/建角，不资助、不改经验/掉落倍率，逐个记录到10级耗时，并核对退出/完整重启后的金币、任务、技能与物品编号。素材只读复用；源版本不受修改。

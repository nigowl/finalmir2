# 客户端功能对照扫描

2026-11-24 更新。对照 Git 历史 `65cb83bd^` 的三个场景（登录、选角、游戏）、36 个 Dialog 源文件（107 个公开类）和 GameScene 的 258 个服务端包分支，检查当前 `src/Client`、`src/Client.Core` 的界面入口、TCP 请求、状态归约及场景绘制。原引擎规则是否开放取决于所选版本，缺少微端入口不表示服务端规则已删除。

这是源码覆盖扫描与重点实测，不是全部玩法验收。“已接入”表示有实际调用链；“部分”表示主流程存在但原功能仍有缺口；“缺失”表示没有对应完整界面/归约。不能根据窗口数量、包引用数量推算完成百分比。

## 包级扫描附件

[36个原界面文件及107个类](CLIENT_PARITY_DIALOGS.tsv)列出全部界面扫描范围；[258项包级对照表](CLIENT_PARITY_PACKETS.tsv) 逐行列出原 GameScene 包编号、当前共享类型和静态匹配。补记本人受推、困魔、门回执、NPC输入、技能移除、名称颜色、行会宣战、建会命名、场景名称增量和绑定物品主人查名后，结果为164项有直接引用、1项由继承归约（`ObjectHero → ObjectPlayer`）、93项未发现专门处理。

这些数量是检索证据，不是93个独立玩法缺失或165项全部验收。继承分支、普通聊天提示、地图整体刷新等可覆盖部分表现；反过来，引用一个包也可能只做显示而没有完整资产/取消流程。表中未发现处理的类型已按上表功能归类；协议定义、测试注入和原引擎自身引用均没有冒充微端实现。

## 在线技能移除专项（2026-11-24）

原客户端 `RemoveMagic.PlaceId` 是技能列表下标，不是技能枚举。原引擎临时技能卸除、NPC `RemoveSkill` 和 GM 删除均发送该包。微端现在按合法下标移除本人技能，清除此技能的启用/禁用开关，重建技能行并即时清除快捷图标；保留其他技能的键位/冷却、英雄技能及已生效Buff。技能行事件按当前技能身份查找，防止删除前项后旧控件施放或改绑下一项。被移除的待发技能和职业等待取消，但未决毒符换装编号仍等原回执，不因技能消失解除资产锁。

`bash tests/Compatibility/skill-removal.sh`在独立副本构建与导入资源。1001项客户端检查通过；真实Godot/原TCP使用隔离角色依次学习/移除基础剑术、火球、魔法盾，确认旧保留技能行仍真实施盾、已删除技能旧控件无法错施/改绑、快捷栏与空列表更新。待移动施法及未决换装是本地状态注入检查；魔法盾实际扣50MP并收到真实Buff，移除技能不擅自消除此Buff。正常退出、服务端保存停服及完整重启后仍无已删技能与旧快捷键，SQLite完整性正常。证据 `mir2-skill-removal.DMRk5j/`，画面已核对，两次客户端日志无Godot引擎错误；仍有既有声音0缺源提示。未更新正式实例，未将隔离GM删除等同于逐个装备临时技能或NPC移除脚本全部验收。

## 名称颜色专项（2026-11-24）

原 `ColourChanged` 只更新本人，`ObjectColourChanged` 只更新已知且非本人的场景对象。微端现已同步本人资料与场景颜色，登录使用 `UserInformation.NameColour`，名称绘制使用各对象原包颜色，不在客户端猜测PK、行会或敌我关系。未知对象不创建，切图后的迟到颜色包不能复活旧对象，换角清理沿用现有流程。`UserName` 是灵魂绑定物品所有者名称缓存，`ObjectName` 是场景名称更新，本颜色专项当时尚未处理；后续专项已分别补齐ObjectName和绑定主人UserName查名，不混同颜色与身份处理。

仍有既有声音0缺源提示；本名称专项当时未更新正式实例，之后的正式更新与行会战争验证见下节。下一轮继续按优先清单核对在线物品状态及名称缓存；合成材料消耗和完整结果链尚缺，不能仅补封印/槽位增量就宣称合成玩法完成。

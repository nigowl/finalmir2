# 经验、任务导航与公共商店

击杀经验直接使用服务端 `GainExperience.Amount`，每次正数回执在聊天显示“获得经验 +数量”。升级和任务经验也沿用实际回执，不根据经验条差值估算。

任务追踪和详情中的目标文字可点击，悬停变白并显示下划线；没有出现在正文中的目标补充“前往 名称”。未完成的击杀目标按真实名称前缀对应刷怪点，收集目标按真实正概率掉落来源定位，交付使用当前实际 NPC 对象。跨地图只沿普通步行出口逐段查询；沿途开门、碰撞、组队地图权限保持，地图路线显示在小地图。到 NPC 附近打开其正常对白，仍由玩家接交任务。挂机时先确认停止；Esc、手动移动/选怪、死亡、退出取消导航。遇障碍、缺目标、出口拒绝和查询超时给出提示，不传送或改任务进度。

导航定位公开刷怪区域，并不保证区域存在活怪或沿途安全。剧情洞口、脚本条件传送和攻城出口不自动执行。图内由现有寻路计算，临时占用导致不可达时停止。

游戏菜单左侧使用原商城图标 `Prguse 826/827/828`。未配置时，公共商店分药水、卷轴、符毒、补给、技能五页，列出当前版本定义中的：普通恢复药、回城/随机卷、护身符/红绿毒粉、基础火把、坐骑饲料、魔血石，以及当前可见正常NPC金币货架实际出售且存在技能定义的无绑定职业技能书。排除装备、任务物、特殊药和增益卷；不把未出售的稀有书或任务书凭空加入商城。商品以实际物品编号成交；同组只有一个商品时直接显示商品与购买入口，多规格才显示价格区间和二级展开。只使用当前版本已有定义。

补给页还提供建会材料沃玛角。每件固定 100 万金币，使用当前版本已有的普通材料定义。任务物品“沃玛号角”不在目录内。

其他商品取该玩家当前 NPC 最低金币单价，含该 NPC 费率和适用税率。没有货架的普通补给取物品定义售价，再乘 `Game/PublicShopPriceRate` 并向上取整。默认 1.5（加价50%），管理端“系统设置 → 成长与掉落”可调 1–10，保存立即生效。客户端确认报价，服务端购买时重新核对真实目录和价格，旧价拒绝后需刷新确认。

购买入口为x1/x10/x100透明文字按钮，确认框可改数量（最多999件/包）。毒粉与护身符按整包购买，展示每包使用次数。购买复用 `CreateFreshItem / InventoryStacks.CanAdd / GainItem / LoseGold` 即时入包，在扣款前模拟全部堆叠及格位，并检查死亡/交易、数量、金币范围与小数负重；无法容纳整批时全部拒绝。每名角色保留最后采购编号与结果，重复请求仅回放结果；客户端只允许单个未决采购，关闭、切图和死亡不会释放未知结果锁，5秒提示超时但不重发，收到对应回执或断线后清理。成功物品/金币反馈进小地图下方，失败进聊天。

小地图下方物品消息文字右对齐、背景及边框透明，保留阴影、三秒消失、最多四条和鼠标穿透。

只在包枚举末尾追加公共商店及任务导航包，由资源清单 `publicShop` / `questNavigation` 声明能力；原包字段与保存布局不变。旧服务端不发送新请求；客户端提示更新服务端。

专项验证入口与实测边界见 `tests/README.md` 的同名条目。

## 补给规格与魔血石

新增规格通过受版本锁保护的离线命令初始化：正常保存停服后执行 `MIR2_DATA_ROOT=所选版本目录 dotnet src/Server/bin/Release/net8.0/Mir2.Server.dll --prepare-public-shop`，命令完成后再正常启动。已更新的服务端也支持受保护管理接口 `POST /management/development/public-shop/prepare`，由游戏线程备份并保存世界，无需重启引擎。初始化补齐缺少的定义及新编号，并把本功能旧100/300/500次规格升级为500/1000/2000次；保留原编号、单次价格及玩家剩余次数。重复执行不再新增或更新，同名但类型或未知规格冲突时拒绝。保留版本备份，物品仍归所属版本SQLite。

护身符、绿毒、红毒各小/中/大为500/1000/2000次；新定义没有耐久，旧毒符的详情也统一显示剩余次数。每包独立占格，施法仍由原GetAmulet规则实际扣次数。公共商店仅上架这九项，旧无规格商品不再上架，已有物品、其他NPC货架和掉落引用仍保留；单次价格不变，整包价格按新次数计算。

魔血石小/中/大储量为100000/300000/500000，单重0.1，装备在火把栏。每2秒生命、魔法各最多恢复30点，按实际恢复量共用储量；满血满蓝不消耗，死亡、禁药地图及交易时暂停。储量耗尽后保留空石并提示更换，不删除或自动重购。不能修理、强化或分解来补充储量，售价按剩余比例下降。

储量使用追加Stat.MagicBlood与物品已有整数属性保存，AddedStats记录已消耗的负值，原RefreshItem同步客户端；它不计入人物战斗属性，不改变物品包字段或存档布局。现有自动保存周期保持，未实现逐笔落盘。

## 陪玩使用公共服务

陪玩缺普通红蓝药、回城卷时直接读取公共商店报价并原地购买，不再为了商城已有商品的NPC低价跨图。药品按原职业储备线/人格预算采购，无红且只够一瓶仍保留最低一瓶例外；可用药优先于卷轴和发展。正常职业技能书按真实技能等级、职业、已学/包内状态购买，执行时只处理服务端本次确认的商品编号，再走原UseItem学习；已学灵魂火符且护符不足25次时补一包，500/1000/2000次的包数与次数分开计算，不把50次缺额误买50包。装备升级、修理和任务接交仍由原NPC/原权限执行。

普通余货按陪玩现有全版本任务、配方材料/工具、备装、未来等级装备和特殊资产保护清单主动原地回收，不等背包塞满；普通材料/食物跨堆至少留5份。服务器给出允许唯一编号/数量，执行端再复核，走原RecycleItem半价与实际金币/删物回执。其他应保留或暂存的物品继续原仓库流程，不把玩家显式勾选回收策略套到陪玩。

公共采购及回收纳入原串行资产锁：匹配请求号（回收还匹配唯一编号及数量）后才释放；拒绝保留资产并暂排除目标，5秒未知停止且不重发、不自动技术重连。切图、死亡、轮换和暂停都不能清掉未决资产。目录读取是只读操作，超时暂排除重规划。私有陪玩语义修订13须配套宿主/Shared/执行组件，原游戏公共服务包字段与存档不变。


## 商城管理

管理端“商城”页面设置当前版本1–8个选项卡（名称1–16字、可排序）与各栏商品；搜索当前版本物品名称/编号添加、修改金币单价或移除。全商城最多512项，同一物品只能出现一次；不接受任务专用品、脚本物、封印英雄和无有效技能的书籍。默认单价0沿用既有NPC/定义与商城倍率规则，非0为管理员明确设置的每件/包金币价，优先于默认倍率与沃玛角默认定价。修改默认报价商品定义为0价前须先改商城单价或移除商品，避免生成无法加载的配置。

编辑为草稿，取消不写入，关闭未保存内容与保存/删除均确认。受版本校验的`GET/PUT /management/shop`及`GET /management/shop/items`在游戏线程执行；保存沿用AdminChanges完整备份/事务/失败回滚，并清玩家旧报价。数据位于当前版本SQLite的`settings/public-shop.json`快照，Schema=1；未知/损坏格式保留并拒绝加载，不静默还原默认。未配置时只读生成旧货架，不自动持久化目录。刷新/重新打开商城读取新名称、顺序、商品和价格，保存本身不重启服务。

资源清单`publicShopLayout`声明追加选项卡能力；新请求返回页签包和既有商品包，旧请求不收到新布局包，原商品包字段不变。购买继续走服务端真实目录、金币、空间、合堆、小数负重和幂等回执，后台改价后旧报价拒绝。

验证入口为`--shop-catalog-checks`（也包含在`--public-services-checks`）；`tests/Management/shop.cjs`覆盖浏览器草稿/确认/页签与商品编辑；Godot `--verify-shop-catalog`验证两个自定义页签、单项直接购买/多规格展开与真实金币/入包；隔离`--shop-catalog-session 游戏端口 记录文件`检查新旧请求、改价/篡改拒绝、重复请求和资产，完整正常重启后追加`--verify-save`。

# 微端界面规范

保留原版花角、金边、棕底及专用物品格；界面按1024×768逻辑画布排版，窗口/DPI缩放交给现有画布。不因统一样式修改地图格子、装备槽或HUD原素材坐标。

选角支持每账户5个未删除角色，列表原390px高区域按5个78px位置等分；原背景烘焙的四个空框同步接成五个，裁切保留完整四边，卡片、文字、职业图标和预览沿用原素材。当前选中卡片使用持续金边和淡金底色，悬停仅轻度提亮且不切换选中项；点击切换时高亮与人物预览同步，同一时间只选中一项。第六个由客户端提示和服务端共同拒绝，五职业开关与原IP建角保护保留。

英雄只有明确的Summoned状态才显示“休息”并允许选择模式；Dead显示服务端剩余秒数并禁用召唤，冷却资料未知时显示“恢复中”。初次召唤先初始化生命/魔力再发送完整资料；死亡后60秒才可普通重召，恢复最大生命10%且最低1点，冷却结束不自动召唤。休息重召不回满生命，死亡计时随英雄保存，换角/换英雄不能串用。复活卷仍遵守同一60秒限制，冷却内拒绝不扣卷，到期保留原卷的满血效果。

GM按上次保存位置进入游戏，原登录处理结束后弹出NPC式“是否进入管理员地图？”，可选择“进入管理员地图”或“留在当前位置”；关闭等同保留当前位置。确认继续走原r001脚本和管理员权限检查，普通角色不收到提示，也不能伪造链接进入。登录原本已在管理员地图时仍按存档位置进入。

## 字体与字号

字体统一使用随包的`NotoSansCJKsc-Regular.otf`，由`ClientUi`定义字号层级：

| 用途 | 逻辑字号 |
| --- | --- |
| 弹窗标题、角色名称标题 | 12 |
| 正文、操作按钮、页签、菜单 | 11 |
| 聊天、HUD数值、辅助说明 | 10 |
| 快捷标记、技能熟练度等紧凑信息 | 9 |

登录、选角、背包、任务、角色、组队、仓库、行会、交易及设置的操作文字使用动态文字，不混用素材内烘焙的书法字。角色卡片的名字/等级/职业标签也由控件绘制。原版Mir标志和无文字功能图标作为美术保留。长标题在原范围内省略，保留全文提示；多行属性和公告从上方排版。

## 按钮与页签

- 普通文字按钮：26逻辑像素高，左右8、上下3像素内边距；使用原`Title 276–278`加工的凸起棕底、细金边三态。标题栏和底栏内对齐，同排等高；输入框与操作按钮对齐中心线。
- 页签：24逻辑像素高，左右8、上下1像素内边距，使用`GameTab`主题。从原角色`Title 500`选中图和`Title 504`未选中图分别取无字两侧，保留完整20像素高度、圆角金边、棕色渐变和高光。当前页使用原选中图，悬停提亮；不另画扁平底线。人物、任务筛选、仓库、行会、公共商店及设置共用。
- 同组页签等宽、固定4像素间距，当前页唯一高亮。选中图裁掉右侧透明留白，未选中图去掉相邻页签边线，两态共用同一透明轮廓；核对可见边缘间距，不能只检查控件矩形。悬停/选中不改变文字内边距、尺寸或邻近内容位置。任务奖励、物品格和商品列表继续使用各自交互样式。
- 图形关闭按钮仍用原素材独立三态，不叠加方形悬停背景。嵌入确认窗只有一层外框。
- 任务窗口的选择奖励及任务行使用透明文字按钮，金色正文、悬停下划线、选中白字；底栏接取/交付/放弃/关闭及放弃确认使用统一棕底金边按钮。右上角关闭图标和任务物品格保留专用外观。NPC任务名单从`(9,34)`开始，每行19像素、零行间距，适配背景五行及原列线；选中标记、两字状态、名称分别占列，状态及标记的Label继承中文字体后再固定19像素高，避免默认字号撑高后文字偏低。“可接”使用绿色，长名称省略并提供全文提示。
- 背包/任务物品和行会已有完整原版底图，不能再在下方叠画通用外框；裁掉底图外围透明空列并清除烘焙关闭图标，按真实像素大小绘制。行会面板匹配590×432原图，底部说明避开角饰和边线。
- 控件加入父节点继承中文主题后再定尺寸，避免Godot默认字体的最小尺寸使按钮或输入控件被撑大。原素材准备完成后，等主题的最小尺寸更新完成再延迟设置页签高度，避免被旧主题撑成25px。
- 独立页签使用同组互斥选择，按下时立即切换，避免松开前新旧页签同时高亮；未选中项悬停只提亮自身底图，不能临时套用选中图。选中项悬停保持同一底图和字号，松开不改变边线或文字像素。

## 标题与间距

- 标题栏高32像素；标题文字框高24像素，距顶4像素、通常距左12像素。角色/交易姓名按面板居中，避开关闭按钮。
- 背包“任务物品”“仓库物品”均为82×26像素，水平间距4像素。人物四页签均58×24像素，间距4像素，整组242像素宽、左右各留11像素，不能伸入角色面板边线。
- 普通正文以12像素左内边距为基准；专用原版格子及滚动条按其素材位置保留。底栏按钮、任务奖励长文本及技能快捷键不得撑出面板。
- PopupMenu二级菜单的箭头和加速键占用同一右侧位置；攻击模式的`Ctrl+H`提示放入该项标题，保留实际快捷键处理，避免箭头盖住文字。
- 游戏设置保持原`440×350`窗口及背景，底栏“重置”和保存提示仅下移到`Y=319`，均高26像素并按中心线对齐；提示在按钮左侧，长错误单行省略、悬停显示全文，不扩大或改绘背景。

## 装备详情与行内控件

- 全五职业通用装备不显示职业要求行；单职业限制、等级、性别与负重等要求仍按服务端定义显示。将多职业装备改为全职业是版本世界定义变更，不由界面绕过穿戴权限。
- 装备详情和同位对比共用限高滚动区，内容最多360逻辑像素，短内容按实际高度收缩。超高详情出现滚动条后，鼠标停留在物品格上滚轮上下查看，不关闭提示或滚动下层列表；短提示不拦截所在列表的滚轮。移出物品格仍沿用原生提示的关闭行为。详情保留列间/差异分隔线和条件红字，使用约72%不透明的紧凑深色1像素细边框、8像素内边距，不用花角；移除“滚轮查看”文案，耐久0/0隐藏、0/正数保留。普通技能短提示仍为不透明背景。
- 商品等列表滚动后，原生提示的延迟回调可能仍指向旧行，构建详情时以视口实际悬停的物品格为准；提示内容及滚轮目标均随实际物品更新。
- 技能行高46像素、行距2像素，36×36图标和24像素高的快捷键控件都与行中心对齐。名称和等级/熟练度各一行，被动技能隐藏快捷键控件。背包、装备和快捷栏等物品格与技能图标为图案留边。
- 技能图标、名称及快捷技能格共用中文悬停说明：功能/效果、主动/被动/开关状态、冷却、基础耗蓝和已传输的施法距离。冷却取当前服务端`ClientMagic.Delay`，保留烈火10秒、反击7秒的原准备限制；被动/攻击开关不伪造施法冷却。不给原协议未传输的实际伤害或持续时间编造固定数值，未实现技能明确提示。
- 技能列表与F1–F12图标只显示各自`CastTime + Cooldown`，遮罩比例采用该技能真实冷却长度；公共施法间隔仍限制输入，不叠加到其他图标。零独立冷却、被动及攻击开关不伪造倒计时。
- 保护设置每行的复选框、生命/魔力条件和百分比输入均高28，按中心线对齐；四个阈值同列。百分比输入使用原按钮底图的专用`GamePercent`主题，职业自疗阈值共用，不影响登录等普通输入框。
- 大小地图使用64×64透明底边框，保留通用弹窗24像素花角中的原金色像素，抠除烘焙暗底、散点及角饰内侧的底纹。边框下方完整绘制地图和不透明面板底色，角区不能透出背后的场景。通用框和完整对话框先裁掉原图右侧2px透明留白，再切九宫格，避免右边线断开及新建角色框角区透明。直边只画4像素原边线，内侧透明，不以黑色宽边遮住地图，不再把角饰缩小一半。标题、地图名称和坐标文字避开两端角饰，小地图仍保留上/右8像素间距。

## 账户仓库

仓库窗口显示仓库一至四四个68×24原图页签，每页沿用80格；仓库一默认开放。未开通页保留锁定底图，显示当前版本真实开通任务、等级、NPC、地图及坐标；提示通过只读`/game/storage-unlocks`读取，不在客户端硬编码NPC或任务名称。当前default二/三/四页分别配置任务33/64/112，须顺序完成，同账户未删除角色共享完成资格；登录与原任务成功交付后由服务端永久开通。

背包入口仍只预览，实际存取须原仓库NPC会话、密码、距离与服务端有效容量校验；未开通页不能存取。租用扩展和既有仓库资产保留，未解锁格不因选择页签获得权限。资源初始化先准备资源URL及缓存目录，再等待仓库提示HTTP请求，防止界面提前取图后把空元数据留在缓存。

## 地图交互

大地图左键沿原路线寻路，右键向原服务端发送`@mv X Y`坐标传送请求，不预改角色坐标；小地图右键和地图留白不触发传送。权限由原MOVE规则校验：GM或已穿传送装备，保留原TestServer设置、NoPosition地图限制、普通玩家10秒冷却及落点校验，成功/拒绝由聊天回执提示。加载中、死亡或未连接不发送；挂机中先确认停止，取消保持挂机，旧确认不跨图执行。`@mm`仍用于按地图名称/代码切图。

## 物品设置

设置共五页：基础、保护、挂机、职业、物品。“自动拣取”开关位于挂机页；物品页使用暗色复选框表格，按显示/拣取/回收/物品四列列出完整目录，支持搜索和自动保存。“自动回收”默认关闭，手动与挂机均生效。保持440×350背景、底栏和统一字体，表头复用游戏按钮素材；完整行为与资产保护边界见`CLIENT_SKILLS.md`。音效检查范围见`CLIENT_AUDIO.md`。

基础页音量使用复选框和音量条：取消勾选立即静音，保留原百分比，重新勾选恢复；静音也作用于正在播放的声音，异步音效不补播。旧设置缺少音量开关时保留原音量。鼠标操作使用“走跑互换”复选框，未选中为左键走、右键跑，选中互换，沿用原DefaultRun存储值。CRT弧面/扫描线控件各128逻辑像素、间隔10像素，标签与参数分开，不改变窗口尺寸。

“显示血条”默认关闭，选中后显示视野内可见且存活的人物、英雄、怪物和召唤物；不依赖名称开关或选中目标。血条有效长度48逻辑像素、黑边外宽50，高5像素；使用固定站立帧的身体中线实体顶部，位于实际头顶上方并留空隙，不跟随名字位置、当前朝向或动作帧抖动，避开长矛/翅膀和阴影。血条上方以9号字显示实际`当前HP/最大HP`。精确血量通过清单`healthDisplay`能力和追加的原TCP请求/回执传输，每个角色会话只初始化一次，之后沿原生命/属性变化及对象进出视野更新；未请求的客户端不收新包，原ObjectHealth布局和编号保持。隐藏、视野外或未知对象不建立血量状态；未获得精确值时不按百分比编造数字。关闭选项恢复原选中怪物血条，仍接收本次会话增量以免再次开启出现旧值。左下血魔球只保留原图形，不叠加生命/魔力文字。

伤害及治疗飘字取原生命变化前后的差值：护卫秒杀只显示被击杀对象实际剩余HP，护身转蓝及未扣HP不显示虚假扣血，治疗不显示超过上限的溢出量。训练靶保留原DPS聊天统计，不把未扣除的HP作为伤害飘字；原命中/暴击、抗性、护卫秒杀、经验/掉落及返回伤害值保持。专项入口为`--health-display-checks`和隔离Godot的`--verify-health-display`，完整重启追加`--verify-health-save`。

## 连续动画、移动与短时消息

选角造型按原`ChrSel`职业/性别起图、16帧和250ms间隔播放；先预备整段，素材未就绪时保留已显示帧，不以空白替代。换角色重新预备，不绘制上一角色的缓存造型。

世界各层继续共用同一帧时刻和镜头，但按实际屏幕整数像素取整，避免2.5倍等高DPI画布每次跳一整逻辑像素。人物与英雄连续走跑按近期真实回执间隔从当前视觉位置接续，先经过上一段确认终点再转向，避免画面斜切拐角；不预测权威坐标或越过确认终点。超过三格或非八方向的普通位置纠正直接对齐确认格，技能冲刺、跳跃及攻击位移独立使用原动作时长，不继承普通走跑间隔或34ms显示余量。行进中预备路线前五格的转向走跑素材；HUD文字/技能说明每100ms刷新，动画、冷却遮罩和动作处理仍逐帧运行。地图素材路径按原映射一次生成有界表，避免绘图热路径反复创建字符串。

小地图不显示地图名称及底部标题空白，大地图保留标题。小地图下方增加右对齐的220像素宽消息区，最多同时四条，每条最多三行；背景不透明度68%，显示约3秒并在末350ms淡出。获得/丢弃/使用/扣除/购买/出售/穿戴/修理及金币等成功反馈只在这里显示，以服务端回执为准；错误、系统、聊天、命令仍进入聊天框。玩家聊天不能通过伪造购买成功前缀进入物品消息区。消息不拦截鼠标，大地图展开时隐藏，退出角色清理。挂机保留当前有效战斗优先，结束后先在原八格范围拣取符合名单的掉落，再选择新怪；保留同格排除、金币上限及未决请求保护。已收到到格回执即可发原PickUp，不再额外等一段走路动画，也不在位置未确认时提前拾取。

已有隔离原生fixture可用`--verify-smooth`核对冷/热缓存选角完整帧、原TCP金币守恒/新怪候选优先级、消息位置/鼠标穿透/消失、攻击后原战斗姿势、24格跑步及物理像素对齐。另有一次明确注入的250ms帧调度延迟，验证下一回执仍跑两格；它不计入性能样本。`--profile-motion`仅做选角和移动采样，`--profile-actors`采样80个本地绘制对象；均不能指向正式实例。

## NPC、背包与任务物品

NPC对白内提供金色悬停下划线“查看 任务”，对白包含“关闭”链接时排在该行上方，不再占用底栏。商店只显示商品列表，无返回按钮；同类型同名商品去重为一级，显示单价或价格区间，展开后保留每个实际商品编号、价格、图标和详情。购买与出售先确认数量，取消不发资产请求；确认后单个待回执，超时不重发，旧确认不可跨地图或NPC会话执行。

物品快捷栏占用0–5号格，使用类道具放在这些格位时只在快捷栏显示。普通背包默认另有80格，每行8格、共10行，使用同一套尺寸、底色和格线。标题仅显示“背包”，英雄上下文为“背包·英雄”；金币、负重及空闲数值在底栏，容量仍按服务端实际值显示在空闲提示中。旧服若仍下发46个总格位，普通背包仍提供40格。既有扩展格保留并可滚动访问。若0–5号格已有非使用类物品，背包仍提供取回入口，避免物品不可见。

仅`ItemType.Quest`任务专用品自动归入独立任务栏，不占普通背包容量；普通任务材料仍在背包。登录整理和后续获取保留数量及物品编号；任务栏满时拒绝新增，旧背包专用品原样保留并提示，不删除物品。NPC专用品检查和交付使用任务栏；完成/放弃只清理该任务关联的无用专用品，不误删无关专用品。

## CRT滤镜

采用CRT-Mattias风格的弧面、RGB色散、荧光晕、扫描线、暗角和轻微闪烁，使用五次屏幕采样；弧面强度0–5级（0为平面）与扫描线强度1–5级独立调整，均默认3级并自动保存。横向扫描线按768逻辑行交替，RGB三色荧光列按实际屏幕像素采样，适配高DPI。关闭后恢复原像素，滤镜不阻挡鼠标。灰色采样块仅用于专用原生测试的瞬时定量检查，正常客户端及最终游戏截图均不显示。

## 原素材阴影

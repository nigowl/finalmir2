# 微端界面规范

保留原版花角、金边、棕底及专用物品格；界面按1024×768逻辑画布排版，窗口/DPI缩放交给现有画布。不因统一样式修改地图格子、装备槽或HUD原素材坐标。

## 字体与字号

字体统一使用随包的`NotoSansCJKsc-Regular.otf`，由`ClientUi`定义字号层级：

| 用途 | 逻辑字号 |
| --- | --- |
| 弹窗标题、角色名称标题 | 12 |
| 正文、操作按钮、页签、菜单 | 11 |
| 聊天、HUD数值、辅助说明 | 10 |
| 快捷标记、技能熟练度等紧凑信息 | 9 |

登录、选角、背包、任务、角色、组队、仓库、行会、交易及设置的操作文字使用动态文字，不混用素材内烘焙的书法字。角色卡片的名字/等级/职业标签也由控件绘制。原版Mir标志和无文字功能图标作为美术保留。长标题在原范围内省略，保留全文提示；多行属性和公告从上方排版。

## 按钮与页签

- 普通文字按钮：26逻辑像素高，左右8、上下3像素内边距；使用原`Title 276–278`加工的凸起棕底、细金边三态。标题栏和底栏内对齐，同排等高；输入框与操作按钮对齐中心线。
- 页签：24逻辑像素高，左右8、上下1像素内边距，使用`GameTab`主题。从原角色`Title 500`选中图和`Title 504`未选中图分别取无字两侧，保留完整20像素高度、圆角金边、棕色渐变和高光。当前页使用原选中图，悬停提亮；不另画扁平底线。人物、仓库、行会及设置共用；任务窗口筛选使用下述文字按钮样式。
- 同组页签等宽、固定间距，当前页唯一高亮。选中图裁掉右侧透明留白，未选中图去掉相邻页签边线，两态共用同一透明轮廓；核对可见边缘间距，不能只检查控件矩形。悬停/选中不改变文字内边距、尺寸或邻近内容位置。任务奖励、物品格和商品列表继续使用各自交互样式。
- 图形关闭按钮仍用原素材独立三态，不叠加方形悬停背景。嵌入确认窗只有一层外框。
- 任务窗口的筛选、选择奖励及任务行使用透明文字按钮，金色正文、悬停下划线、选中白字；底栏接取/交付/放弃/关闭及放弃确认使用统一棕底金边按钮。右上角关闭图标和任务物品格保留专用外观。NPC任务名单从`(9,34)`开始，每行19像素、零行间距，适配背景五行及原列线；选中标记、两字状态、名称分别占列，状态及标记的Label继承中文字体后再固定19像素高，避免默认字号撑高后文字偏低。“可接”使用绿色，长名称省略并提供全文提示。
- 背包/任务物品和行会已有完整原版底图，不能再在下方叠画通用外框；裁掉底图外围透明空列并清除烘焙关闭图标，按真实像素大小绘制。行会面板匹配590×432原图，底部说明避开角饰和边线。
- 控件加入父节点继承中文主题后再定尺寸，避免Godot默认字体的最小尺寸使按钮或输入控件被撑大。原素材准备完成后，等主题的最小尺寸更新完成再延迟设置页签高度，避免被旧主题撑成25px。
- 独立页签使用同组互斥选择，按下时立即切换，避免松开前新旧页签同时高亮；未选中项悬停只提亮自身底图，不能临时套用选中图。选中项悬停保持同一底图和字号，松开不改变边线或文字像素。

## 标题与间距

- 标题栏高32像素；标题文字框高24像素，距顶4像素、通常距左12像素。角色/交易姓名按面板居中，避开关闭按钮。
- 背包“任务物品”“仓库物品”均为82×26像素，水平间距4像素。人物四页签均59×24像素，间距2像素，整组242像素宽、左右各留11像素，不能伸入角色面板边线。
- 普通正文以12像素左内边距为基准；专用原版格子及滚动条按其素材位置保留。底栏按钮、任务奖励长文本及技能快捷键不得撑出面板。
- PopupMenu二级菜单的箭头和加速键占用同一右侧位置；攻击模式的`Ctrl+H`提示放入该项标题，保留实际快捷键处理，避免箭头盖住文字。
- 游戏设置保持原`440×350`窗口及背景，底栏“重置”和保存提示仅下移到`Y=319`，均高26像素并按中心线对齐；提示在按钮左侧，长错误单行省略、悬停显示全文，不扩大或改绘背景。

## 装备详情与行内控件

- 全五职业通用装备不显示职业要求行；单职业限制、等级、性别与负重等要求仍按服务端定义显示。将多职业装备改为全职业是版本世界定义变更，不由界面绕过穿戴权限。
- 装备详情和同位对比共用限高滚动区，内容最多360逻辑像素，短内容按实际高度收缩。超高详情出现滚动条后，鼠标停留在物品格上滚轮上下查看，不关闭提示或滚动下层列表；短提示不拦截所在列表的滚轮。移出物品格仍沿用原生提示的关闭行为。详情保留列间/差异分隔线和条件红字，使用约72%不透明的紧凑深色1像素细边框、8像素内边距，不用花角；移除“滚轮查看”文案，耐久0/0隐藏、0/正数保留。普通技能短提示仍为不透明背景。
- 商品等列表滚动后，原生提示的延迟回调可能仍指向旧行，构建详情时以视口实际悬停的物品格为准；提示内容及滚轮目标均随实际物品更新。
- 技能行维持40×40图标及两行文字；名称框和熟练度框各高24，熟练度与窄快捷键控件的中心线对齐。被动技能继续隐藏快捷键控件。
- 技能图标、名称及快捷技能格共用中文悬停说明：功能/效果、主动/被动/开关状态、冷却、基础耗蓝和已传输的施法距离。冷却取当前服务端`ClientMagic.Delay`，保留烈火10秒、反击7秒的原准备限制；被动/攻击开关不伪造施法冷却。不给原协议未传输的实际伤害或持续时间编造固定数值，未实现技能明确提示。
- 保护设置每行的复选框、生命/魔力条件和百分比输入均高28，按中心线对齐；四个阈值同列。百分比输入使用原按钮底图的专用`GamePercent`主题，职业自疗阈值共用，不影响登录等普通输入框。
- 大小地图使用64×64透明底边框，保留通用弹窗24像素花角中的原金色像素，抠除烘焙暗底、散点及角饰内侧的底纹。边框下方完整绘制地图和不透明面板底色，角区不能透出背后的场景。通用框和完整对话框先裁掉原图右侧2px透明留白，再切九宫格，避免右边线断开及新建角色框角区透明。直边只画4像素原边线，内侧透明，不以黑色宽边遮住地图，不再把角饰缩小一半。标题、地图名称和坐标文字避开两端角饰，小地图仍保留上/右8像素间距。

## 账户仓库

仓库窗口显示仓库一至四四个68×24原图页签，每页沿用80格；仓库一默认开放。未开通页保留锁定底图，显示当前版本真实开通任务、等级、NPC、地图及坐标；提示通过只读`/game/storage-unlocks`读取，不在客户端硬编码NPC或任务名称。当前default二/三/四页分别配置任务33/64/112，须顺序完成，同账户未删除角色共享完成资格；登录与原任务成功交付后由服务端永久开通。

背包入口仍只预览，实际存取须原仓库NPC会话、密码、距离与服务端有效容量校验；未开通页不能存取。租用扩展和既有仓库资产保留，未解锁格不因选择页签获得权限。资源初始化先准备资源URL及缓存目录，再等待仓库提示HTTP请求，防止界面提前取图后把空元数据留在缓存。

## 地图交互

大地图左键沿原路线寻路，右键向原服务端发送`@mv X Y`坐标传送请求，不预改角色坐标；小地图右键和地图留白不触发传送。权限由原MOVE规则校验：GM或已穿传送装备，保留原TestServer设置、NoPosition地图限制、普通玩家10秒冷却及落点校验，成功/拒绝由聊天回执提示。加载中、死亡或未连接不发送；挂机中先确认停止，取消保持挂机，旧确认不跨图执行。`@mm`仍用于按地图名称/代码切图。

## 连续动画、移动与短时消息

选角造型按原`ChrSel`职业/性别起图、16帧和250ms间隔播放；先预备整段，素材未就绪时保留已显示帧，不以空白替代。换角色重新预备，不绘制上一角色的缓存造型。

世界各层继续共用同一帧时刻和镜头，但按实际屏幕整数像素取整，避免2.5倍等高DPI画布每次跳一整逻辑像素。普通玩家连续走跑按近期真实回执间隔从当前视觉位置接续，不预测权威坐标、不越过已确认终点，停顿过长或技能位移不套用旧间隔。行进中预备路线前五格的转向走跑素材；HUD文字/技能说明每100ms刷新，动画、冷却遮罩和动作处理仍逐帧运行。地图素材路径按原映射一次生成有界表，避免绘图热路径反复创建字符串。

小地图不显示地图名称及底部标题空白，大地图保留标题。小地图下方增加右对齐的220像素宽消息区，最多同时四条，每条最多三行；背景不透明度68%，显示约3秒并在末350ms淡出。获得/丢弃/使用/扣除/购买/出售/穿戴/修理及金币等成功反馈只在这里显示，以服务端回执为准；错误、系统、聊天、命令仍进入聊天框。玩家聊天不能通过伪造购买成功前缀进入物品消息区。消息不拦截鼠标，大地图展开时隐藏，退出角色清理。挂机保留当前有效战斗优先，结束后先在原八格范围拣取符合名单的掉落，再选择新怪；保留同格排除、金币上限及未决请求保护。已收到到格回执即可发原PickUp，不再额外等一段走路动画，也不在位置未确认时提前拾取。

已有隔离原生fixture可用`--verify-smooth`核对冷/热缓存选角完整帧、原TCP金币守恒/新怪候选优先级、消息位置/鼠标穿透/消失、攻击后原战斗姿势、24格跑步及物理像素对齐。另有一次明确注入的250ms帧调度延迟，验证下一回执仍跑两格；它不计入性能样本。`--profile-motion`仅做选角和移动采样，`--profile-actors`采样80个本地绘制对象；均不能指向正式实例。

## NPC、背包与任务物品

NPC对白内提供金色悬停下划线“查看 任务”，不再占用底栏。商店只显示商品列表，无返回按钮；同类型同名商品去重为一级，显示单价或价格区间，展开后保留每个实际商品编号、价格、图标和详情。购买与出售先确认数量，取消不发资产请求；确认后单个待回执，超时不重发，旧确认不可跨地图或NPC会话执行。

物品快捷栏仅接受使用类道具，装备、肉、材料和任务专用品不能放入；普通背包滚动显示完整46格，原6–45格顺序保持，0–5格放在末行，避免过滤快捷栏后旧装备无法访问。

仅`ItemType.Quest`任务专用品自动归入独立任务栏，不占普通背包容量；普通任务材料仍在背包。登录整理和后续获取保留数量及物品编号；任务栏满时拒绝新增，旧背包专用品原样保留并提示，不删除物品。NPC专用品检查和交付使用任务栏；完成/放弃只清理该任务关联的无用专用品，不误删无关专用品。

物品单重由共用`ItemInfo.UnitWeight`计算：装备保留标准重量；任务专用品为1；其他物品按版本内标准重量除以100，限制在0.01–1。普通红蓝药的小/中/大/特大规格对应0.01/0.02/0.03/0.04，保留当前版本定义的规格差异；零标准重量的非装备按最低0.01计算。普通堆叠按数量累计，例如101份小药总重1.01，护符/鱼饵仍按原整包重量计算。任务专用品在独立任务栏时不计普通背包负重。服务端、客户端和陪玩采购/存取/超重预检共用小数重量；背包、HUD和详情最多显示两位小数，堆叠详情区分单重和总重。原`Weight`字节、协议与存档布局保留。

地面金币按真实数量使用以下`DNItems`素材，名称和拾取仍保留完整金币数；兑换物品沿用其实际物品图标与原兑换规则。

| 金币数量 | 外观 | 素材帧 |
| --- | --- | --- |
| 少于100 | 少量金币 | 112 |
| 100–999 | 中量金币 | 114 |
| 1,000–999,999 | 大量金币 | 116 |
| 1,000,000–4,999,999 | 金条 | 117 |
| 5,000,000–9,999,999 | 金砖 | 121 |
| 10,000,000及以上 | 金盒 | 122 |

隔离原生fixture使用`--verify-item-weight --weight-record=记录文件`核对六档实际绘图、药品买/用/丢/拾、37金币守恒及小数提示；正常停服重启后同参数追加`--verify-save`，核对物品编号/数量、金币和重量。

选角创建恢复五职业，造型按实际资源映射，女弓箭手从`ChrSel 160`开始；刺客和弓箭手的商店/掉落继续使用当前世界定义。选角页提供删除角色按钮及角色名/等级/职业确认，单个待确认、超时不自动重发，成功后按返回角色编号更新列表。职业智能辅助仍仅覆盖战士、法师、道士。

## CRT滤镜

强度1–5级有界递增，默认3级。横向扫描线按768逻辑行交替，RGB三色荧光列和点阵按实际屏幕像素采样，避免高DPI缩放后纹理消失；仅保留轻微暗角，不加入模糊或时间闪烁。关闭后恢复原像素，滤镜不阻挡鼠标。灰色采样块仅用于专用原生测试的瞬时定量检查，正常客户端及最终游戏截图均不显示。

## 素材与文字分离

本轮只读核对81帧实际界面及候选素材，不修改版本内原`.Lib`或向微端打包游戏素材。`OriginalArt.Skins`从所选服务端资源生成以下通用纹理：

| 用途 | 原素材 | 处理与使用 |
| --- | --- | --- |
| 普通按钮三态 | `Title 276–278` | 保留左右边饰及纵向渐变，移除中间文字，九宫格适配宽高；用于登录/选角及游戏操作按钮 |
| 页签选中/未选中 | `Title 500 / 504` | 各取无字左右8像素，保留原角色页签形状，横向伸展到人物59、仓库/行会68、任务85等宽度 |
| 角色窗口 | `Title 504` | 页签区域用正文完整横截面接续两侧边线，清除旧字及原折角；不能仅用矩形填色截断边框。原底图独立绘制，不再叠通用外框 |
| 角色卡片 | `Title 658–663` | 五职业按枚举使用658–662，战士658为剑、法师659为杖、道士660为扇。从同一纵向无字列修复三个标签区域，保留职业图标、外框和值字段，动态绘制标签和角色值 |
| 通用弹窗/菜单/地图 | `Prguse 995` | 先裁外围透明空列，通用框角饰的旧底纹改为一致面板底色；地图角饰下绘制地图或实底。保留原金色花纹和边线，关闭按钮独立绘制 |

`Title 30/31/32/40`登录标题、账号/密码及SELECT文字不再直接绘图；所有当前`Title`文字按钮均提供动态标题。行会旧英文统计标题与不匹配的烘焙字段框改为中文文字和分隔线。原始资源保持可回溯，换资源版本/重连后沿用现有缓存重新生成。

本次不增加语言选项、翻译字典或国际化依赖。按钮底图不含操作文字，界面字符串继续使用当前中文；以后多语言可替换文字而无需重新制作按钮图片。

## 登录账号弹窗

登录页“注册账号”和“修改登录密码”分别打开完整的独立模态弹窗，共用原版花角边框、关闭图标、动态文字及棕底金边按钮。注册填写账号、密码、确认密码和选填邮箱；改密填写账号、当前密码、新密码及确认新密码，只预填账号，不借用登录框里的密码。账号仍限3–15位、密码5–15位英文字母或数字，邮箱通过原NewAccount字段提交，不增加验证码或邮箱找回功能。

两个弹窗的标签同列、输入框28px高、底部按钮等宽且26px高；原生AcceptDialog会重设按钮尺寸，使用这两个窗口的局部主题常量固定最小宽高。校验/拒绝反馈在当前弹窗显示，支持回车提交、取消、Esc和右上角关闭，关闭时清除密码。注册成功沿用原有自动登录到选角流程；关闭注册后才到达的成功回执只提示重新登录，不自动跳页。

注册和改密共用单个待确认请求，提交后锁定两份表单，10秒未收到回执仍保持锁定且不重发；取消/关闭不视为撤销已发送请求。晚到回执释放锁，断线/重连清理旧表单与请求状态，切换场景不遗留模态窗口。错误账号、重复账号、当前密码错误、未开放及封禁保留原服校验与中文反馈。

## 原素材阴影

原Lib中的部分人物、NPC和树木阴影使用深色实点/透明空点交错的点阵模拟半透明；最近邻放大后会显出明显棋盘格。这属于素材像素，与CRT开关无关。

`OriginalShadowPixels`仅在场景纹理首次上传前，把同色深色（RGB各通道≤16）、全不透明与全透明交错的2×2对角格恢复为128Alpha；已有半透明、实色、彩色图案及界面/技能特效保持原样。不扩张轮廓、不做全屏模糊，仍使用最近邻缩放。原Lib、网络帧、校验值和磁盘缓存均不变，重启客户端重新生成GPU纹理即可，无须清缓存。

`--shadow-checks`验证识别及像素保护和真实素材，隔离Godot的`--verify-shadows`核对实际上传纹理并用独立SubViewport渲染地图，不登录或改动角色。截图在实际FramePostDraw后读取，避免后台窗口截取旧帧。此处理只还原明确的原点阵，不自动推断任意新素材的阴影编码。

## 验证

隔离Godot使用`--verify-storage-pages`验证四个原图页签、唯一选中、真实NPC/地图/任务提示、原密码及锁定第四页的原TCP存入拒绝/源编号保持。使用已有测试NativeSmoke账号，不在正式服创建测试账号；`--supplies-storage-checks`及隔离任务交付/完整重启覆盖320格权限与资产保持。

`MIR2_TEST_KEEP=1 MIR2_NATIVE_VISIBLE=1 MIR2_TEST_SCREENSHOTS=1 ./tests/Compatibility/smoke.sh`在临时版本/独立端口运行真实Godot、原TCP及SQLite重启检查。

`bash tests/Compatibility/accounts.sh`只构建相关项目并在临时版本运行真实Godot账号表单检查：输入列/密码遮掩/按钮对齐、独立字段、模态阻挡、本地校验、注册/重复账号、改密拒绝/成功、新旧密码登录、回车/取消/Esc/关闭及未决/超时/晚到回执。不运行完整游玩/管理/部署套件，不改正式数据。

纯界面迭代优先构建客户端，再在保留的隔离smoke实例上使用`godot --path src/Client -- --server=隔离资源服务地址 --verify-ui --screenshot=绝对路径.png`。该入口检查人物页签两侧连续边线/八次切换、技能悬停说明、背包/行会单层框、地图角区、智能组合收起/展开、拣取名单保存，以及重置确认/取消/写盘失败，不执行战斗、交易或完整重启套件；账号固定为隔离fixture的`NativeSmoke`，不能指向正式实例。启动脚本自动登录另有独立成功/拒绝检查，不因后续像素微调反复执行整套。

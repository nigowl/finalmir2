# 管理界面规范

本规范适用于 FinalMir2 管理端全部页面、嵌套弹窗和后续新增功能。沿用 MudBlazor 与 AdminDialog，不按单页自行设置另一套按钮外观。

页面、弹窗及接口反馈只描述功能、必要条件和生效范围，不反复强调“原版、原客户端、原引擎、原服”等实现历史。真实限制、备份/确认、需重启及资产保护必须保留。系统设置当前值旁显示默认值；重置只更新草稿，保存前仍确认。

## 按钮

| 位置/用途 | Size | Variant / Color | 高度 |
| --- | --- | --- | --- |
| 页面主要新增、主要保存、系统设置编辑 | Small | Filled / Primary | 32px |
| 查询、刷新、预览、查找、重载、辅助入口 | Small | Outlined / Default；强调辅助动作可用 Primary | 32px |
| 表格行编辑、管理、详情、选择 | Small | Text / Primary | 28px |
| 表格行上线/恢复、暂停/下线、删除/移除 | Small | Text / Success、Warning、Error | 28px |
| 页面批量上线、批量下线、危险入口 | Small | Outlined / Success、Warning、Error | 32px |
| 弹窗底部保存/确认、取消 | Small | Filled / Primary；Text / Default | 32px |
| 分页前后翻页 | Small | Text / Default | 32px |
| 关闭、连接测试等图标 | Small | Default 或既有状态色；必须提供 aria-label | 28×28px |
| 顶栏导航图标、退出 | Small / 原生按钮 | 中性风格 | 32px |
| 登录表单主按钮 | Medium | Filled / Primary，全宽 | 40px |

同一用途使用同一变体、大小和颜色；普通辅助操作不全部堆成实心主按钮。危险入口用红色，停用/踢下线/重启等警示入口用黄色，恢复/上线用绿色；文字内容说明实际影响。通用确认框的提交是主操作，保持主色。

每个手写 MudButton 显式声明 Size、Variant、Color；图标按钮显式 Size、Color 和 aria-label，不依赖组件默认值。表格行操作统一文字按钮，并在操作单元格标记 `admin-row-actions`；共享样式提供同语义色1px细边框，保持28px高度和6px间距。最终尺寸由共享 `app.css` 按位置固定实际height及min-height，防止flex工具栏将按钮拉高；资源下载沿用相同行操作按钮，搜索工具栏输入框与按钮垂直居中。禁止单页通过任意内联 padding/font-size 制造新尺寸。

按钮使用“保存、取消、关闭、查询、刷新、编辑、上线、下线”等简洁文案。备份、事务、覆盖、重启及风险说明放在说明或确认正文，不能塞进“备份并保存…”一类按钮名称。陪玩列表的“批量日程设置 / 批量上线 / 批量下线 / 批量LLM设置”同放在已选角色工具栏，紧邻排列，页面顶栏只保留新增、设置与刷新。保持禁用、处理中、防重复提交、保存确认和关闭保护；美化不能削弱业务保护。

地图中的 NPC/点位图形是原素材交互目标，保留真实尺寸和定位，不套用普通文字按钮高度。

## 页签、表格和弹窗

- 页签标题等分撑满可用整行，标题和活动指示线对应；头部按文字和6px上下内边距自然撑开，不保留默认48px最小高度或下方空带。
- 页签内容保留14px分隔（窄屏12px），不与标题紧贴。页签及内容块不加卡片外框、圆角或阴影；表格不加最外层边框/圆角，保留表头及内部行分隔。
- 所有页面保持紧凑字体、行高、表头、操作列与分页风格。仍允许地图/图鉴等有明确用途的内部列分隔，不能因取消外框而去掉必要结构。
- 左上项目名固定 FinalMir2，可返回管理首页；版本标签继续明确显示当前版本。
- 编辑沿用 AdminDialog：标题、内容、底栏分隔，右上关闭；“取消 / 保存”位于右下，只有主操作使用实心强调；没有操作时隐藏底栏。
- 新增页面和调整现有页面均先匹配邻近页面及本规范，不重新设计另一套界面。
- 全部怪物使用自适应卡片瀑布流，纵向长条布局，上方原图，下方编号/名称及紧凑的等级/生命/攻击/防御/魔御/基础经验，底部分页居中，不恢复列表表头或外部左右属性分栏。点击卡片另开“属性 / 掉落”编辑弹窗，内容区高度稳定、内部滚动，切换和异步加载不改变弹窗高度/位置；底部“取消 / 保存”，确认后提交；查找怪物复用卡片并保留“选择”。属性按身份/等级经验、战斗、行为脚本分组，原有非零属性及额外属性均可编辑；掉落公共目录支持多级筛选/多关键词搜索，普通数量可省略默认1。app.css按内容哈希生成URL以更新旧缓存；说明与保存边界见 `MONSTER_MANAGEMENT.md`。

刷怪地图缩放显示实际百分比，最大1:1（每格48×32像素）；全图使用缩略图，放大后从原素材按当前层级重新渲染可见块，复用原地图块API，不放大缩略图。缩放保留视口中心，命中检测继续使用SVG矩阵逆变换。地图模块import使用静态文件内容哈希版本，避免升级后复用旧接口。刷怪标记用正常12px字号及逆向缩放保持屏幕尺寸，数量为80%，不能用亚像素字号再随地图放大。同坐标的多组刷怪合并显示组数及合计数量，点击选择具体刷怪编号；相同半径只绘制一次，不改原定义。选择列表超过10项分页，全部配置仍可访问。刷怪地图标记使用怪物名称首个完整字符和较小字号的数量，悬停或键盘聚焦保留完整名称、坐标、数量和半径。范围以逻辑格圆形计算，依原地图48×32比例投影；半径随地图同比缩放，颜色保持浅淡，不拦截范围内部布点。阻挡中心与原引擎共用最近可走格修正，实际中心在悬停中提示。

## 检查

`python3 tests/Management/style.py` 检查全部手写按钮声明与表格行变体；`tests/Management/ui.sh` 的最终逐页检查覆盖11个管理页面，核对按钮32/28px、无外框表格、等宽铺满页签和头部最小高度。改动弹窗还需实际浏览器检查；截图核对不得仅凭编译通过。

`python3 tests/Management/spawn-map.py`在独立版本检查同页面预载旧模块后的升级、放大/缩小往返、全图/1:1、窗口变化、文字像素尺寸及格中心、标记实际点击与取消后配置保持。
